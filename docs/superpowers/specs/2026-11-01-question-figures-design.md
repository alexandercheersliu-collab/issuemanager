# 整卷逐题图形与同类题图形设计

## 背景与目标

当前整卷导入只保存题目所在页的 `image_path`。校对、复习等页面若展示它，会带入整页其他题目和无关信息；若只展示文字，几何题又缺少必要条件。AI 变式目前明确把 `image_path` 置空，同类题检测返回结构也不包含图片，因此生成题无法显示图形。

目标是：

1. 视觉切题时自动识别每道题包含的图形区域，并保存为逐题图片。
2. 校对、错题本、今日复习和同类题场景优先展示当前题的图形，完整原页仍可回看。
3. AI 变式沿用原题图形，保持图形结构、点的位置和字母标注不变，只修改数值或设问。
4. 图形识别或裁剪失败不阻断导入，老数据继续可用。

## 非目标

- 不生成新的几何图形，不允许 AI 变式随意改变原图结构或标注。
- 不引入 SVG/TikZ 渲染或新的图片生成模型。
- 不强制为历史任务批量补图；历史任务无裁剪图时回退原页。当前 `几何1.jpg` 作为真实验收样例补图。
- 不改变公共题库检索、SM-2 调度或判分算法。

## 数据契约

### 视觉切题

`segment_page` 的每个题目元素增加可选字段：

```json
{
  "number": "1",
  "text": "题干",
  "figure_bboxes": [[530, 110, 950, 490]],
  "continued_from_prev": false,
  "continues_to_next": false,
  "likely_wrong": false
}
```

`figure_bboxes` 为 0–1000 归一化坐标 `[x0, y0, x1, y1]`，相对于当前页图宽高。每道题可有多个图形；无图形时省略或返回空数组。模型只框图形及必要标注，不框整道题或整页。

### 切题与任务结果

`Segment` 增加 `figure_paths: list[str]`。视觉页完成坐标识别后，使用 Pillow 将图形裁剪到当前导入任务的工作目录，文件名含页码、题序和图序，避免并发冲突。

规则/视觉结果对齐时，视觉图形路径附加到规则文本；跨页题合并时按页序拼接图形路径。任务 `result.segments[*]` 持久化 `figure_paths`。

### 错题记录

`questions` 新增可空 JSON 列 `figure_paths`，默认空列表。`QuestionOut` 同步增加该字段，并像 `image_path` 一样解析数据目录迁移后的有效路径。

- `image_path`：完整原页，用于回溯。
- `figure_paths`：当前题的一张或多张裁剪图，用于日常展示和同类题。

仓储创建方法、整卷确认入库及 ORM 转换均传递该字段。老记录没有此值时按空列表处理。

### 同类题检测

`start_detection` 返回的 `tested` 增加 `figure_paths`。该路径用于当前挑战的展示，不改变检测日志和判分数据结构。

## 处理流程

1. 整卷视觉切题时，模型返回题干及可选图形坐标。
2. 坐标经过类型、范围、面积校验并裁剪到页图边界；非法值跳过并记录日志。
3. 切题合并、跨页拼接和人工合并保留图形；人工拆分时图形留在起始段，避免后半题错误继承全部图形。
4. 确认入库将逐题 `figure_paths` 写入错题记录。
5. 页面有裁剪图时优先展示裁剪图，无裁剪图时按现有逻辑回退原页。

## 页面行为

- **整卷校对**：有裁剪图时默认只显示当前题图形，完整原页放入“查看完整原页”；无裁剪图时保留现有原页预览。
- **错题本详情**：题干旁展示当前题图形，完整原页可展开查看。
- **今日复习**：题干正面显示必要图形，解析仍点击后显示。
- **同类题检测**：在检测题干前展示 `tested.figure_paths`。
- **录题后的相似题列表**：带图候选在题文附近展示对应图形。

## AI 变式约束

`_generated_as_question` 复制原题的 `figure_paths`。原题有图时，`_generate_variant` 向分析模型增加约束：

- 变式必须沿用原图。
- 图形结构、点的位置、字母及标注保持不变。
- 只修改数值、已知条件或设问，不新增或删除图中元素。

变式仍走现有文本分析管线，不新增图片生成调用。无图题行为不变。

## 容错与兼容性

- 缺失、非法或零面积坐标只影响对应图形，不使整卷失败。
- 裁剪异常按题记录日志；该题回退原页。
- 模型未返回 `figure_bboxes` 时按空列表处理，兼容现有 MockProvider 和旧测试。
- 数据库迁移只增加字段，不重写现有 `image_path` 或题目文本。
- 当前 `几何1.jpg` 任务完成实现后重新执行图形识别，保留已生成解析，仅补充任务和题目的图形资源。

## 验证

采用测试驱动开发，每个行为先添加失败测试：

1. AI 切题坐标解析及缺失字段兼容。
2. 坐标校验、边界裁剪、多图保存。
3. 规则/视觉合并、跨页合并、人工合并与拆分中的图形归属。
4. 数据库迁移、确认入库及 `QuestionOut` 路径传递。
5. AI 变式复制图形及有图生成约束。
6. 同类题检测返回和 Streamlit 图片展示。
7. 使用 `几何1.jpg` 真实视觉调用检查裁剪内容，并确认变式展示同一图形。
8. 全量 `pytest` 和全项目 Ruff 均通过。
