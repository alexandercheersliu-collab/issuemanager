# Issues Manager 用户手册

> AI 错题本 · 视觉大模型 × RAG 检索 · 间隔重复复习
> 适用版本：Windows 本地部署包 v2.1.0

---

## 1. 安装与首次启动

### 1.1 系统要求

- Windows 10 / 11（64 位）
- 约 1.5 GB 可用磁盘空间
- 使用 AI 解析功能需要能访问所选大模型服务的网络

### 1.2 安装

1. 将 `IssuesManager-x.x.x-windows-x64.zip` 解压到任意目录
   （建议路径不含中文与空格，例如 `D:\Apps\IssuesManager`）。
2. 双击 `IssuesManager.exe` 启动，**无需安装**。

> 若 Windows SmartScreen 提示"已保护你的电脑"：点击「更多信息」→「仍要运行」。
> 这是未购买代码签名证书的常态提示，程序本身不修改系统。

### 1.3 首次启动：配置大模型

首次运行会自动进入**配置向导**（黑色控制台窗口中交互）：

1. 按编号选择大模型服务商（推荐 SiliconFlow 或通义千问，新用户有免费额度）；
2. 回车确认 BASE_URL 与推荐模型；
3. 粘贴 API Key，向导会**发起一次真实调用验证**——验证通过才写入；
4. 配置写入程序目录下的 `.env` 文件，同时自动生成安全密钥。

选择"0. 暂不配置"则以**演示模式**运行（内置示例解析，不调用真实 AI），
之后随时可在程序目录执行 `IssuesManager.exe --reconfigure` 重新配置。

### 1.4 每次启动与停止

- 双击 `IssuesManager.exe`：自动打开浏览器进入桌面端（`http://localhost:8501`）；
- 停止：在控制台窗口按 `Ctrl+C`，或直接关闭窗口。

### 1.5 默认账号

首次启动自动创建两个账号（**请登录后尽快在「设置 → 修改密码」中更改**）：

| 账号 | 密码 | 用途 |
|---|---|---|
| `admin` | `admin123` | 管理员（后台管理、数据维护） |
| `demo` | `demo123` | 学生（日常使用） |

## 2. 大模型配置说明

### 2.1 服务商对照表

| 服务商 | 推荐模型 | Key 申请 |
|---|---|---|
| SiliconFlow（硅基流动） | `Qwen/Qwen2.5-VL-32B-Instruct` | cloud.siliconflow.cn |
| 通义千问（阿里云百炼） | `qwen-vl-plus` | bailian.console.aliyun.com |
| 智谱 GLM | `glm-4v-flash` | open.bigmodel.cn |
| DeepSeek | `deepseek-chat` | platform.deepseek.com |
| Ollama（本机自建） | `qwen2.5vl:7b` | 无需 Key，需先安装 Ollama |
| Google Gemini | `gemini-2.0-flash` | aistudio.google.com |

**注意**：错题解析依赖图片识别，模型必须具备**视觉能力**（VL 系列），
纯文本模型（如 deepseek-chat）只能用于文字追问，拍照录题会失败。

### 2.2 修改配置

- 方式一：执行 `IssuesManager.exe --reconfigure` 重走向导；
- 方式二：直接编辑程序目录下的 `.env` 文件（改完重启程序生效）。

## 3. 桌面端使用（电脑浏览器）

启动后浏览器自动打开 `http://localhost:8501`，登录后左侧导航：

- **学情看板**：录入量、复习量、正确率趋势与知识图谱总览；
- **AI 录题**：拍照/上传错题图片 → AI 自动找题、勾选后逐题解析入库
  （支持多选图片、整页多题自动切分；等待期间页面会逐题显示进度）；
- **整卷导入**：整份试卷 PDF/DOCX 或逐页图片导入，异步切题后确认入库；
- **标准题库**：仅教师/admin 可见，用于搜索、编辑和安全删除共享标准题；
- **错题本**：语义搜索（如「判别式没掌握的题」）、筛选、编辑、发起同类题检测；
- **今日复习**：基于间隔重复（SM-2）的闪卡复习，按记忆程度四档评分；
- **知识图谱**：知识点关联可视化；
- **AI 助手**：自然语言对话——「本周学习报告」「搜索 判别式」「把第 3 题原题发我」
  「录入一道错题…」「第 5 题我记得了，评 good」；
- **设置**：修改密码、标签管理、数据备份、存储路径查看。

### 3.1 共享标准题与匹配确认

拍照和整卷录入会先查 SQL 标准题库：规范化题干完全一致时显示「精确复用」并直接复用
题干、答案、解析及合规共享图；相似题即使分数很高也只显示候选，必须明确选择
「引用此题」或「作为新题解析」，后者才会调用 AI。未命中则按新题解析。学生的新题通过完整性
和结构校验后也会进入共享标准题库，后续学生可精确复用；不完整种子题不会成为空解析个人错题。
完全相同且只对应一道完整标准题的教师原始文件可直接命中，但不会把学生指向题库原文件。教师
发布保留原文哈希，学生再次上传相同文档时可少做重复解析。

每次引用仍保存本次上传的学生私有原图。PDF 有页图时保存对应页图；DOCX 没有固有页图，
则保存该 DOCX 的私有证据副本，不用空白图片代替；副本写入失败会回到可重试状态，不会卡在
确认中。同一确认批次引用同一 DOCX 时共享该批次的私有副本，删除其中一道题不会提前删除其他
存续题目仍在使用的文件。Mobile 的录入结果、错题详情和复习页会显示 DOCX 类型，即使题目带图
也可通过鉴权接口下载原始文档。

### 3.2 Web 题库权限矩阵

| 角色 | 搜索/查看管理详情 | 编辑标准题 | 删除未引用标准题 | 删除被引用标准题 |
|---|---|---|---|---|
| 学生 | 无权限 | 无权限 | 无权限 | 无权限 |
| 教师 | 可以 | 可以 | 可以 | 无权限 |
| admin | 可以 | 可以 | 可以 | 预览影响并二次确认后可以 |
| 未登录 | 无权限 | 无权限 | 无权限 | 无权限 |

教师可在「标准题库」按关键词、学科、年级、教材、题型、来源和引用数筛选，编辑题干、
答案、解析、知识点、题型和上下文。教师/admin 可查看题库原始图片；这些图片不会作为
学生资源返回。Mobile 不提供标准题库搜索、编辑、删除或管理导航。

教师删除未引用题会清理对应题库资源和向量。admin 删除被引用题前会看到受影响学生用户名、
个人错题 ID 和引用数，并须输入页面给出的固定确认短语；若预览后引用数变化，必须重新预览。
删除后学生个人错题以题干/答案/解析/元数据快照继续显示，私有原图、个人覆盖、复习记录、
评论和检测记录保留。编辑和删除均写审计；普通搜索不写审计。

### 3.3 私有证据、共享图与删除

- 学生原图、手写裁剪图、备注、错因和复习状态只属于本人，在个人错题存续期间始终保留；
  学生主动删除自己的错题时才物理清理其私有原图和私有裁剪图。
- 题库原始图片只供教师/admin 管理，不向学生展示或引用。不依赖私有原图的 AI 重绘图
  作为共享资产复用；一个学生删除错题不会删除其他学生仍在使用的共享图。
- 最后一名学生删除引用后，学生来源的孤儿标准题及其共享 AI 图和向量会自动清理；
  教师或种子来源题不会因此被自动删除。
- SQL 删除成功但向量/文件清理失败时，系统保留可重试的对账或清理任务；不会把已删除的
  SQL 标准题恢复成半成品，也不会把失败显示为完全成功。

## 4. 手机端使用（手机/平板）

1. 手机与电脑连接**同一 Wi-Fi**；
2. 启动程序时控制台会打印手机端地址，形如 `http://192.168.1.100:8000/m/`；
   （也可在电脑上执行 `ipconfig` 查看 IPv4 地址后自行拼出）
3. 手机浏览器打开该地址，登录同一账号；
4. 浏览器菜单选「添加到主屏幕」，之后可像 App 一样全屏使用。

> 首次访问若弹出 Windows 防火墙提示，勾选「专用网络」并允许。
> 手机端包含：今日复习、拍照录题、AI 助手（支持**语音输入**，需浏览器授权麦克风）、
> 错题本、个人中心。

**拍照录题**：在「录题」页拍照或从相册选择一张/多张 JPG、PNG、WEBP 图片，可按需填写
标签和备注。识别出多题时勾选要录入的题目（疑似错题已默认选中）；单题照片会自动解析
入库，无需候选确认。完成页会分别显示入库、重复和失败结果。刷新或切走后可恢复未完成
任务，完成后可进入错题本查看。

**整卷导入**：在「录题」页底部点「拍的是一整张试卷？试试整卷导入 →」，选择一份
PDF/DOCX，或按页序选择最多 20 张试卷照片。解析完成后可核对题目、删除误切题或对单题
「重新解析」，再确认入库；结果页显示入库和跳过数量，可展开查看跳过原因。未确认任务
在刷新后仍可恢复。

错题详情、复习和同类题检测会显示服务端返回的题面、解析和有效图；图形仅为原图裁剪时
会提示核对准确性。手机端不提供文字录入、K12 信息表单、题干/解析编辑、合并/拆分或
TikZ 编辑。当前录题默认使用数学、10 年级、上海、沪教版；注册时采集这些偏好并自动
替代默认值属于后续功能，当前尚未提供。

## 5. 数据与备份

- 所有数据保存在程序目录的 `data/` 内（SQLite 数据库、题目原图、向量索引），
  **卸载只需删除整个程序目录，不会在系统其他位置留下数据**；
- 备份：复制整个 `data/` 目录即可；也可在「设置 → 数据备份」导出/导入 JSON；
- 迁移到新电脑：整体复制程序目录（含 `data/`）即可直接使用；SQL 是标准题权威来源，
  ChromaDB 只是可重建索引。使用迁移脚本更换数据目录后，按提示运行种子导入和
  `scripts/reindex_vectors.py`，不要手工把旧向量 ID 当作标准题 SQL ID。

## 6. 常见问题（FAQ）

**Q：启动后浏览器没有自动打开？**
手动访问 `http://localhost:8501`；确认控制台窗口没有被关闭。

**Q：提示"端口被占用"？**
8501 或 8000 端口被其他程序占用：关闭之前的 Issues Manager 窗口，
或在任务管理器结束残留的 `IssuesManager.exe` 进程后重启。

**Q：AI 解析报错 / 一直失败？**
检查 `.env` 中的 Key 是否有效、账户是否有余额、模型是否为视觉模型（VL）；
可执行 `IssuesManager.exe --reconfigure` 重新验证配置。

**Q：搜题结果不准确？**
默认使用内置小型嵌入模型，中文召回一般。追求更佳效果可在 `.env` 配置远程嵌入
（`EMBEDDING_BASE_URL` / `EMBEDDING_API_KEY` / `EMBEDDING_MODEL=BAAI/bge-m3`）。

**Q：手机端打不开？**
确认手机与电脑同一 Wi-Fi、电脑防火墙已放行、地址中的 IP 是电脑当前的局域网 IP
（路由器可能换 IP，建议在路由器后台给电脑做地址绑定）。

**Q：演示模式和真实模式有什么区别？**
演示模式（未配置 Key）的解析结果来自内置示例规则，仅用于体验流程；
配置大模型后才是真正的拍照识别与讲解。
