# Issues Manager 用户手册

> AI 错题本 · 视觉大模型 × RAG 检索 · 间隔重复复习
> 适用版本：Windows 本地部署包 v2.1.0

---

## 1. 安装与首次启动

### 1.1 系统要求

- Windows 10 / 11（64 位）
- 约 1.5 GB 可用磁盘空间
- 使用 AI 解析功能需要能访问所选大模型服务的网络

### 1.2 安装

1. 将 `IssuesManager-x.x.x-windows-x64.zip` 解压到任意目录
   （建议路径不含中文与空格，例如 `D:\Apps\IssuesManager`）。
2. 双击 `IssuesManager.exe` 启动，**无需安装**。

> 若 Windows SmartScreen 提示"已保护你的电脑"：点击「更多信息」→「仍要运行」。
> 这是未购买代码签名证书的常态提示，程序本身不修改系统。

### 1.3 首次启动：配置大模型

首次运行会自动进入**配置向导**（黑色控制台窗口中交互）：

1. 按编号选择大模型服务商（推荐 SiliconFlow 或通义千问，新用户有免费额度）；
2. 回车确认 BASE_URL 与推荐模型；
3. 粘贴 API Key，向导会**发起一次真实调用验证**——验证通过才写入；
4. 配置写入程序目录下的 `.env` 文件，同时自动生成安全密钥。

选择"0. 暂不配置"则以**演示模式**运行（内置示例解析，不调用真实 AI），
之后随时可在程序目录执行 `IssuesManager.exe --reconfigure` 重新配置。

### 1.4 每次启动与停止

- 双击 `IssuesManager.exe`：自动打开浏览器进入桌面端（`http://localhost:8501`）；
- 停止：在控制台窗口按 `Ctrl+C`，或直接关闭窗口。

### 1.5 默认账号

首次启动自动创建两个账号（**请登录后尽快在「设置 → 修改密码」中更改**）：

| 账号 | 密码 | 用途 |
|---|---|---|
| `admin` | `admin123` | 管理员（后台管理、数据维护） |
| `demo` | `demo123` | 学生（日常使用） |

## 2. 大模型配置说明

### 2.1 服务商对照表

| 服务商 | 推荐模型 | Key 申请 |
|---|---|---|
| SiliconFlow（硅基流动） | `Qwen/Qwen2.5-VL-32B-Instruct` | cloud.siliconflow.cn |
| 通义千问（阿里云百炼） | `qwen-vl-plus` | bailian.console.aliyun.com |
| 智谱 GLM | `glm-4v-flash` | open.bigmodel.cn |
| DeepSeek | `deepseek-chat` | platform.deepseek.com |
| Ollama（本机自建） | `qwen2.5vl:7b` | 无需 Key，需先安装 Ollama |
| Google Gemini | `gemini-2.0-flash` | aistudio.google.com |

**注意**：错题解析依赖图片识别，模型必须具备**视觉能力**（VL 系列），
纯文本模型（如 deepseek-chat）只能用于文字追问，拍照录题会失败。

### 2.2 修改配置

- 方式一：执行 `IssuesManager.exe --reconfigure` 重走向导；
- 方式二：直接编辑程序目录下的 `.env` 文件（改完重启程序生效）。

## 3. 桌面端使用（电脑浏览器）

启动后浏览器自动打开 `http://localhost:8501`，登录后左侧导航：

- **学情看板**：录入量、复习量、正确率趋势与知识图谱总览；
- **AI 录题**：拍照/上传错题图片 → AI 自动找题、勾选后逐题解析入库
  （支持多选图片、整页多题自动切分；等待期间页面会逐题显示进度）；
- **整卷导入**：整份试卷 PDF 拍照合成导入，异步切题后确认入库；
- **错题本**：语义搜索（如「判别式没掌握的题」）、筛选、编辑、发起同类题检测；
- **今日复习**：基于间隔重复（SM-2）的闪卡复习，按记忆程度四档评分；
- **知识图谱**：知识点关联可视化；
- **AI 助手**：自然语言对话——「本周学习报告」「搜索 判别式」「把第 3 题原题发我」
  「录入一道错题…」「第 5 题我记得了，评 good」；
- **设置**：修改密码、标签管理、数据备份、存储路径查看。

## 4. 手机端使用（手机/平板）

1. 手机与电脑连接**同一 Wi-Fi**；
2. 启动程序时控制台会打印手机端地址，形如 `http://192.168.1.100:8000/m/`；
   （也可在电脑上执行 `ipconfig` 查看 IPv4 地址后自行拼出）
3. 手机浏览器打开该地址，登录同一账号；
4. 浏览器菜单选「添加到主屏幕」，之后可像 App 一样全屏使用。

> 首次访问若弹出 Windows 防火墙提示，勾选「专用网络」并允许。
> 手机端包含：今日复习、拍照录题、AI 助手（支持**语音输入**，需浏览器授权麦克风）、
> 错题本、个人中心。

## 5. 数据与备份

- 所有数据保存在程序目录的 `data/` 内（SQLite 数据库、题目原图、向量索引），
  **卸载只需删除整个程序目录，不会在系统其他位置留下数据**；
- 备份：复制整个 `data/` 目录即可；也可在「设置 → 数据备份」导出/导入 JSON；
- 迁移到新电脑：整体复制程序目录（含 `data/`）即可直接使用。

## 6. 常见问题（FAQ）

**Q：启动后浏览器没有自动打开？**
手动访问 `http://localhost:8501`；确认控制台窗口没有被关闭。

**Q：提示"端口被占用"？**
8501 或 8000 端口被其他程序占用：关闭之前的 Issues Manager 窗口，
或在任务管理器结束残留的 `IssuesManager.exe` 进程后重启。

**Q：AI 解析报错 / 一直失败？**
检查 `.env` 中的 Key 是否有效、账户是否有余额、模型是否为视觉模型（VL）；
可执行 `IssuesManager.exe --reconfigure` 重新验证配置。

**Q：搜题结果不准确？**
默认使用内置小型嵌入模型，中文召回一般。追求更佳效果可在 `.env` 配置远程嵌入
（`EMBEDDING_BASE_URL` / `EMBEDDING_API_KEY` / `EMBEDDING_MODEL=BAAI/bge-m3`）。

**Q：手机端打不开？**
确认手机与电脑同一 Wi-Fi、电脑防火墙已放行、地址中的 IP 是电脑当前的局域网 IP
（路由器可能换 IP，建议在路由器后台给电脑做地址绑定）。

**Q：演示模式和真实模式有什么区别？**
演示模式（未配置 Key）的解析结果来自内置示例规则，仅用于体验流程；
配置大模型后才是真正的拍照识别与讲解。
